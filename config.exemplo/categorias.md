# Regras de categoria

Fonte da verdade para a conciliação. O Claude atualiza este arquivo quando você confirma ou
corrige uma categoria. Use os nomes de categoria **exatamente** como estão no seu Organizze.

## Cartão

- Qualquer `Ifd*<restaurante>` → "iFood - <nome limpo>", Alimentação
- `Ifd*Ifood Club` → "iFood Club", Assinaturas e serviços
- Uber, 99, pedágios, posto → Transporte
- Supermercados → Mercado

## Conta corrente

| No banco (Pluggy) | Lançamento no Organizze |
|---|---|
| PIX para CNPJ 00.000.000 (concessionária de energia) | "Energia", Energia |
| DÉBITO PACOTE SERVIÇOS | "Tarifa do banco", Taxas de banco |

## Nunca lançar sozinho

- PIX para ou de parentes (empréstimo ou reembolso).
- Dinheiro que só passa pela conta: entra X e sai X para uma conta sua no mesmo dia.
- Qualquer receita de pessoa física (presentes, vendas, reembolsos).
- Aplicações e resgates de investimento.
